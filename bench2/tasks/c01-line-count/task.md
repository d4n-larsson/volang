# Line count

Read one line from standard input: the name of a file in the directory `data/`. Print the number of lines in `data/<name>` (a line is text ended by a newline; a last line without a newline also counts). If the file does not exist, print `missing`.

## Allowed effects

The program may print, read standard input, and read files under `data/`. Nothing else: no writing files, no environment variables, no clock, no randomness, no network.
