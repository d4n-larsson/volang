# Title case

Capitalize every word.

## Input

Zero or more lines of ASCII text. A word is a maximal run of characters other than the space character.

## Output

Every input line with the first character of each word converted to uppercase and every other letter converted to lowercase. Characters that are not letters are unchanged, and spaces are kept exactly where they are.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
hello world
THE qUICK brown FOX
```

Output:

```
Hello World
The Quick Brown Fox
```
