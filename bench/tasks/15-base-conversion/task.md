# Base conversion

Write numbers in another base.

## Input

Zero or more lines, each with two integers `n` and `b` separated by a single space, where 0 <= n <= 1000000000000000000 and 2 <= b <= 16.

## Output

For every line, `n` written in base `b` with the digits `0123456789abcdef` (lowercase) and no leading zeros. Zero is written `0`.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
255 16
10 2
```

Output:

```
ff
1010
```
