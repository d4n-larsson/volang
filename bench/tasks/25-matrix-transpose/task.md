# Matrix transpose

Transpose a matrix of integers.

## Input

The first line holds two integers `r` and `c` (1 <= r, c <= 100), the number of rows and columns. Then `r` lines follow, each with `c` integers separated by single spaces.

## Output

The transposed matrix: `c` lines, each with `r` integers separated by single spaces. Line `i` of the output holds column `i` of the input.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
2 3
1 2 3
4 5 6
```

Output:

```
1 4
2 5
3 6
```
