# Palindromes

Decide for each line whether it is a palindrome.

## Input

Zero or more lines of ASCII text.

## Output

For every input line, `yes` if the line reads the same forward and backward when only letters and digits are kept and uppercase letters are treated as lowercase, otherwise `no`. A line with no letters or digits is a palindrome.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
A man, a plan, a canal: Panama
hello
No 'x' in Nixon
```

Output:

```
yes
no
yes
```
