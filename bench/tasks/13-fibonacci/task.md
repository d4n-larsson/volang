# Fibonacci numbers

Compute Fibonacci numbers, where F(0) = 0, F(1) = 1 and F(n) = F(n-1) + F(n-2).

## Input

Zero or more lines, each with an integer `n` (0 <= n <= 90).

## Output

For every line, F(n).

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
0
1
10
```

Output:

```
0
1
55
```
