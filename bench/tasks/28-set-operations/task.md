# Set operations

Compute the union, intersection and difference of two sets of integers.

## Input

Two lines, A and B. Each holds zero or more integers separated by single spaces (an empty line means an empty set). Values may repeat.

## Output

Three lines: the union of A and B, the intersection of A and B, and the values of A that are not in B. Each line lists distinct values in increasing numeric order, separated by single spaces; an empty set gives an empty line.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
1 2 3 4
3 4 5
```

Output:

```
1 2 3 4 5
3 4
1 2
```
