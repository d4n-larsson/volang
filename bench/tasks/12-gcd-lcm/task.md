# GCD and LCM

Compute the greatest common divisor and least common multiple of two numbers.

## Input

Zero or more lines, each with two integers `a` and `b` (1 <= a, b <= 1000000000) separated by a single space.

## Output

For every line, the greatest common divisor and the least common multiple of `a` and `b`, separated by a single space.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
12 18
7 5
```

Output:

```
6 36
1 35
```
