# Longest increasing subsequence

Find the length of the longest strictly increasing subsequence.

## Input

One line with zero or more integers separated by single spaces (at most 1000 of them). The line is empty when there are none.

## Output

One line with the length of the longest subsequence (not necessarily contiguous) whose values are strictly increasing.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
10 9 2 5 3 7 101 18
```

Output:

```
4
```
