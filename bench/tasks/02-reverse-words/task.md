# Reverse words

Reverse the order of the words on each line.

## Input

Zero or more lines. Words are separated by one or more spaces; a line may have leading or trailing spaces, and may be empty.

## Output

For every input line, one line with the same words in reverse order, separated by single spaces, with no leading or trailing spaces. A line without words gives an empty output line.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
hello world
the sky is blue
```

Output:

```
world hello
blue is sky the
```
