# Integer square root

Compute integer square roots exactly.

## Input

Zero or more lines, each with an integer `n` (0 <= n <= 9223372036854775807).

## Output

For every line, the largest integer `r` such that `r * r <= n`.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
16
17
0
```

Output:

```
4
4
0
```
