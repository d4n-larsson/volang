# Prime factorization

Factor numbers into primes.

## Input

Zero or more lines, each with an integer `n` (2 <= n <= 1000000000000).

## Output

For every line, the prime factors of `n` in increasing order, each repeated as often as it divides `n`, separated by single spaces.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
12
13
```

Output:

```
2 2 3
13
```
