# Roman numerals to integers

Convert Roman numerals to integers.

## Input

Zero or more lines, each a valid Roman numeral between 1 and 3999 in standard form, using `I`=1, `V`=5, `X`=10, `L`=50, `C`=100, `D`=500, `M`=1000. A smaller symbol written before a larger one is subtracted (`IV` = 4, `CM` = 900).

## Output

For every line, the value as a decimal integer.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
III
IV
MCMXCIV
```

Output:

```
3
4
1994
```
