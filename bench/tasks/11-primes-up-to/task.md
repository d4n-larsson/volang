# Primes up to n

List all prime numbers up to a limit.

## Input

One line with an integer `n` (0 <= n <= 100000).

## Output

One line with all primes `p` with `p <= n`, in increasing order, separated by single spaces. If there are none, print an empty line.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
20
```

Output:

```
2 3 5 7 11 13 17 19
```
