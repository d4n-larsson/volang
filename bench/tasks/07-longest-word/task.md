# Longest word

Find the longest word in a text.

## Input

Zero or more lines of ASCII text. A word is a maximal run of letters (`a`-`z`, `A`-`Z`); every other character separates words.

## Output

One line with the longest word exactly as written, a single space, and its length. If several words have the greatest length, print the one that appears first. If there are no words, print `none`.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
The quick brown fox
jumped over the lazy dogs.
```

Output:

```
jumped 6
```
