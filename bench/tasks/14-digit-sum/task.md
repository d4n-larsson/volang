# Digit sum and digital root

Compute the digit sum and the digital root of large numbers.

## Input

Zero or more lines, each a non-negative integer written with 1 to 100 decimal digits (it can be much larger than a 64-bit integer).

## Output

For every line, two integers separated by a single space: the sum of the digits, and the digital root (repeatedly replace the number by the sum of its digits until a single digit remains).

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
12345
0
```

Output:

```
15 6
0 0
```
