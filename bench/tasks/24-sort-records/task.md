# Sort records

Sort people by age, then by name.

## Input

Zero or more lines, each holding a name (lowercase letters) and an age (an integer from 0 to 150) separated by a single space.

## Output

The same lines, sorted by age in increasing order. People with the same age are sorted by name in alphabetical order.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
bob 25
alice 30
carol 25
```

Output:

```
bob 25
carol 25
alice 30
```
