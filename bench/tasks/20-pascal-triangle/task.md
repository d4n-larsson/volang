# Pascal's triangle

Print the first rows of Pascal's triangle.

## Input

One line with an integer `n` (0 <= n <= 30).

## Output

`n` lines. Line `i` (counting from 1) holds the `i` numbers of row `i` of the triangle, separated by single spaces. Each row starts and ends with 1, and every other number is the sum of the two numbers above it.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
5
```

Output:

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```
