# Edit distance

Compute the edit distance between two words.

## Input

Zero or more lines, each with two non-empty words of lowercase letters (at most 100 letters each) separated by a single space.

## Output

For every line, the minimum number of single-letter insertions, deletions and substitutions that turn the first word into the second.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
kitten sitting
flaw lawn
```

Output:

```
3
2
```
