# Anagram check

Decide whether two words are anagrams.

## Input

Zero or more lines. Each line holds two words of lowercase letters separated by a single space.

## Output

For every line, `yes` if one word is a rearrangement of the letters of the other (each letter used the same number of times), otherwise `no`.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
listen silent
hello world
```

Output:

```
yes
no
```
