# Binary search

Find values in a sorted list.

## Input

The first line holds zero or more integers in non-decreasing order, separated by single spaces (the line is empty when there are none). Every following line holds one query integer.

## Output

For every query, the 0-based position of the first occurrence of the query in the list, or `-1` if it is not in the list.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
1 3 5 7 9
7
1
4
```

Output:

```
3
0
-1
```
