# 0/1 knapsack

Pick items to maximize total value without exceeding a weight limit.

## Input

The first line holds the capacity `w` (0 <= w <= 1000). Every following line describes one item as `weight value`, two positive integers. There may be no items.

## Output

One line with the largest total value of a set of items whose total weight is at most `w`. Each item can be used at most once.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
10
5 10
4 40
6 30
3 50
```

Output:

```
90
```
