# Count islands

Count the islands on a map and find the largest one.

## Input

Zero or more lines of the same length forming a grid of `#` (land) and `.` (water).

## Output

One line with two integers separated by a single space: the number of islands and the number of cells in the largest island (0 if there are none). An island is a group of land cells connected horizontally or vertically (not diagonally).

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
##..#
#...#
..#..
```

Output:

```
3 3
```
