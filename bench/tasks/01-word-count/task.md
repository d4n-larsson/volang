# Word count

Count the lines and the words of the input.

## Input

Zero or more lines of text. Every line ends with a newline. Words are separated by one or more spaces (there are no tabs). A line may be empty or contain only spaces.

## Output

One line with two integers separated by a single space: the number of lines, then the number of words.

Read the input from standard input and write the output to standard output. Every output line, including the last, ends with a newline.

## Example

Input:

```
the quick brown fox
jumps over

the lazy dog
```

Output:

```
4 9
```
