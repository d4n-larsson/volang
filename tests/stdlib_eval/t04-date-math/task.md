The program gets two arguments: a date `YYYY-MM-DD` and a number of days N (an integer, possibly negative).

Print two lines:
1. `DATE + N days = RESULT (WEEKDAY)`: DATE and N as given, RESULT the date N days later as `YYYY-MM-DD`, WEEKDAY its English name (`Monday` ... `Sunday`);
2. `days in that month: D`: the number of days in RESULT's month.

If the date is not a valid date or N is not an integer, print `invalid input` and exit with status 1.

Effects: `console`.
