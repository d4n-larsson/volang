# The documentation site

The source of <https://d4n-larsson.github.io/volang/> (spec 015).

- `docs/`: the hand-written pages (Getting started, the language guide, the toolchain guide). Every vo
  example follows `specs/015-docs-site/contracts/examples.md` and is checked by `make test`
  (`tests/site_examples.py`).
- Everything else on the site is generated by `tools/site.py` from the toolchain's own sources (the
  reference, the error catalog, `vo doc`, the examples, the security documents, the roadmap, the specs);
  edit those, never the generated pages (they live in `build/` and are not committed).
- `mkdocs.yml`: the site's configuration; `tools/site.py` adds the navigation and the version.
- `pygments_vo/`: the vo syntax highlighter.

```sh
make site          # build/site (the first run creates build/site-venv: needs the network once)
make site-serve    # preview at http://127.0.0.1:8000/
make site-check    # links, agent files, search lookups, contrast, the install steps on a fresh clone
```

**Moving a page:** add its old address to `redirect_maps` in `mkdocs.yml`
(`old/page.md: new/page.md`), so links to it keep working.

**Publishing:** `.github/workflows/pages.yml` builds and publishes on every push to `main` when all checks
pass. One-time setup: Settings -> Pages -> Source: GitHub Actions.
